## Location + map implementation

This feature is implemented using:

- Expo Location for geolocation permissions and current position:
  `RiskZoneMap.tsx`
- react-native-maps for the native map UI:
  `CurrentLocationMap.native.tsx`
- A WebView + Leaflet fallback on Android:
  `leafletMapHtml.ts`
- Backend API to store the user’s risk zones:
  `api.ts:527-566`
- Prisma/Express backend controller to persist those zones:
  `locationShieldController.ts:8-75`

---

## How it works

### 1) User grants location permission
In `RiskZoneMap.tsx:72-103`, it does:

- Location.getForegroundPermissionsAsync()
- If granted, it fetches current position using:
  - Location.getCurrentPositionAsync({ accuracy: Location.Accuracy.Balanced })

That gives the device latitude/longitude.

### 2) Map is shown and user marks risk zones
The UI uses `CurrentLocationMap.native.tsx:18-102`:

- For native map, it renders a MapView
- It shows:
  - user location
  - saved risk-zone markers
  - a circle around each risk zone
  - a draggable “draft” marker for a new risk area

On map press or drag, it updates the draft center and radius.

### 3) Risk zone radius is defined
In `RiskZoneMap.tsx:170-250`, the user can:

- search a place
- tap on the map
- set a radius using the slider
- save the zone

Each zone includes:
- latitude
- longitude
- radius
- name

### 4) Zones are saved to backend
In `api.ts:527-566`, the app calls:

- GET /users/:userId/location-shield/zones
- PUT /users/:userId/location-shield/zones

The backend controller in `locationShieldController.ts:17-75` stores each risk zone in Prisma.

## Background monitoring / alerts

The actual “location shield” protection is done in `locationShieldMonitor.ts:1-146`:

- It reads the current user ID from AsyncStorage
- Fetches saved risk zones
- Uses Location.watchPositionAsync(...) to monitor user movement
- Checks if the user is inside one of the selected zones
- If yes, it schedules a push/local notification

The key logic:

- haversineMeters() calculates distance between current location and zone center
- isInsideZone() checks if the user is within zone.radius + margin
- checkZonesAndNotify() sends a notification if near a risky area

This is the app’s real safety trigger.

## Android-specific map behavior

For Android, `CurrentLocationMap.native.tsx:18-39` does not use the native MapView directly. It falls back to a WebView with Leaflet map HTML generated by `leafletMapHtml.ts`. That file draws:

- user marker
- danger markers
- radius circles
- draggable draft marker

So the app supports map rendering in a platform-friendly way.
